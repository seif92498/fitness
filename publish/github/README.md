# فورمة · نسخة GitHub Pages

فورمة موقع للموبايل بالمصري لمتابعة الأكل والتمرين والوزن والنوم والماية. `index.html` هو الموقع كامل: CSS وJavaScript والخط والصورة وقاعدة الأكلات والتمارين جواه. افتحه في المتصفح من غير تثبيت أو أمر بناء.

## انشره في دقيقتين

1. وإنت مسجّل دخول على GitHub، اعمل [مستودعًا جديدًا](https://github.com/new) باسم `forma` وخليه **Public** علشان GitHub Pages المجاني.
2. ارفع `index.html` في جذر المستودع (مش داخل فولدر)، من **Add file → Upload files** وبعدها **Commit changes**. لو عايز كود التأليف المنفصل كمان ارفع محتويات الحزمة التانية مع الحفاظ على نفس المجلدات؛ ما ترفعش ملف ZIP نفسه.
3. من **Settings → Pages**، عند **Source** اختار **Deploy from a branch**. اختار **`main`** و**`/ (root)`** واضغط **Save**. ابعت اللينك اللي يظهر أعلى نفس الصفحة بعد النشر: `https://USERNAME.github.io/forma/`.

ما ترفعش ملفات `.env` أو مفاتيح API أو أي نسخة احتياطية من سجلك. كل مستخدم بيحفظ بياناته في متصفحه. لينك المشاركة مش فيه بيانات المستخدم.

## تعديل الكود

تقدر تعدّل `index.html` نفسه، أو تعدّل واجهة التطبيق في `fitness-source/` وتعيد إنتاج الملف من جذر الحزمة بـ `node scripts/build-fitness.mjs --pages` (Node.js حديث للاستخدام ده بس، بدون حزم إضافية). لو هترفع الملف فقط، مش مطلوب أي خطوة بناء.

نسخة GitHub Pages بتشغّل التتبع والحسابات والخطط والمراجعة المحلية بدون حسابات أو سيرفر. التحليل الخارجي وتقدير الصور محتاجين استضافة خلفية وإعداد منفصل، ومش متاحين على GitHub Pages. الأرقام تقديرية والمحتوى مش بديل عن نصيحة طبية.
